# Anwar Endris — Developer Portfolio

Personal portfolio of Anwar Endris, a full-stack developer focused on modern
web applications, APIs, and reliable software systems.

## Stack

React · TypeScript · Tailwind CSS · Node.js · NestJS · PostgreSQL · Docker · Python

## Development

Install dependencies:

    npm install

Start development:

    npm run dev

Build:

    npm run build

Lint:

    npm run lint

## Deployment

Deployed to GitHub Pages through GitHub Actions.

Pushes to `main` trigger the production build and deployment workflow.
